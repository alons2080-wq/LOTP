# 🌌 LOTP (Library of the Prompts)

> A curated collection of prompts for AI models in **Spanish 🇪🇸** and **English 🇺🇸**

## 🚀 About

Although the repository is named **Prompts-AI**, the project is officially called:

### ✨ LOTP — *Library of the Prompts*

A growing collection that includes:

* 📦 Existing prompts gathered from different sources
* ✍️ Original prompts created by me
* 🤖 Prompts adapted for multiple AI models
